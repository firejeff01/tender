# 標案搜尋工具軟體化需求規格與技術建議

## 1. 專案目標

將現有 Excel 巨集工具軟體化，改為可安裝的 Windows 桌面應用程式。系統需每日自動從政府電子採購網擷取「當天最新」且符合條件的招標公告，依日期存成每日資料夾內的 JSON 檔案，不使用資料庫。軟體首頁為月份行事曆，預設顯示當月，每一天的格子需顯示該日擷取到的標案筆數；使用者點擊日期或筆數後，進入該日期的標案資料查詢頁，並可沿用現有 Excel 巨集工具的搜尋、快速篩選、檢視連結等功能。即使使用者沒有開啟桌面軟體，系統仍需能在每天固定時間自動執行資料更新。

## 3. 資料來源與擷取條件

### 3.1 資料來源

- 政府電子採購網首頁：`https://web.pcc.gov.tw/pis/`
- 招標查詢頁：`https://web.pcc.gov.tw/prkms/tender/common/advanced/readTenderAdvanced`
- 標案檢視連結格式目前為：`https://web.pcc.gov.tw/prkms/urlSelector/common/tpam?pk=...`

### 3.2 每日擷取時程

- 系統需每天 `17:00` 自動執行資料更新。
- 時區以台灣時間為準。
- 使用者未開啟桌面程式時仍要執行。
- 若 17:00 電腦關機或離線，下一次開機後應可補跑一次尚未完成的排程。
- 每天排程只需擷取「當天最新」的標案資料。
- 每天擷取到的資料需以「擷取日期」建立每日資料夾保存，不應覆蓋過去日期的資料。
- 若同一天重複執行更新，需以標案唯一識別碼去重，避免同一日期內出現重複標案。

### 3.3 招標案條件

需擷取以下招標方式：

- 公開招標
- 公開取得報價單或企劃書
- 經公開評選或公開徵求之限制性招標

註：政府電子採購網下拉選單同時有「公開取得電子報價單」(TENDER_WAY_12) 與「公開取得報價單或企劃書」(TENDER_WAY_2) 兩個不同項目，本系統選用後者（與 Excel 既有資料一致）。實際 option/value 已於 2026-05-11 透過 readTenderAdvanced 查詢頁確認。

查詢日期條件：

- 每日 17:00 排程以當天日期作為公告日期查詢條件。
- 手動更新預設也抓取當天資料。
- 若使用者從行事曆選擇過去日期，可提供「重新抓取此日」功能，但需明確標示這是補抓指定日期，不是每日排程的預設行為。
- 首版需求以「公告日期為當天」作為最新標案定義；若政府網站有更精確的上架時間或異動時間，後續版本可再擴充。

### 3.4 建議擷取欄位

必要欄位：

- 標案唯一識別碼，建議取 `pk` 或詳情頁可解析出的唯一 id
- 機關名稱
- 機關代碼
- 標案名稱
- 標案案號
- 招標方式
- 採購性質
- 公告日期
- 截止投標日期
- 預算金額
- 標案詳情 URL
- 資料所屬日期，通常等於擷取當日或公告日期
- 擷取日期時間
- 資料來源頁 URL

建議加值欄位：

- 履約地點
- 開標時間
- 採購級距
- 是否共同供應契約
- 是否更正公告
- 標案狀態
- 系統自動標籤，例如命中關鍵字、命中地區、命中機關

## 4. 功能需求

### 4.1 資料更新

- 使用者可手動按「立即更新」。
- 系統每日 17:00 自動更新。
- 更新時需依指定招標方式查詢政府電子採購網。
- 更新範圍預設只抓當天最新標案資料。
- 每日資料需分天保存，並供首頁行事曆統計每一天筆數。
- 資料需寫入本機 JSON 檔案，不使用 SQLite、Access、LocalDB 或其他資料庫。
- 支援分頁擷取。
- 支援重試機制，避免網站短暫失敗造成整批失敗。
- 每次更新需寫入執行紀錄：
  - 開始時間
  - 結束時間
  - 成功/失敗
  - 新增筆數
  - 更新筆數
  - 略過重複筆數
  - 錯誤訊息

### 4.2 首頁月份行事曆

首頁需為月份行事曆，且為系統開啟後的預設畫面。

行事曆需求：

- 預設顯示當月。
- 可切換上一個月、下一個月。
- 可快速回到本月。
- 每一天格子需顯示日期。
- 若該日已有爬蟲資料，需在該日格子內顯示資料筆數。
- 當天日期需有明顯標示。
- 有資料的日期需可點擊。
- 點擊日期或該日筆數後，進入該日的資料查詢頁。
- 沒有資料的日期可顯示 `0` 或不顯示筆數，但視覺上需清楚區分。
- 若該日排程執行失敗，需在格子內顯示失敗狀態或警示符號，點擊後可查看錯誤摘要。
- 行事曆月份統計可顯示：
  - 本月累計標案數
  - 今日新增標案數
  - 最近一次更新時間

### 4.3 指定日期資料查詢

使用者從首頁行事曆點擊某一天後，進入該日期的資料查詢頁。此頁需以當天爬回的標案資料為主要資料集，並參考既有 `.xlsm` 的搜尋與篩選功能。

- 頁面需顯示目前查詢日期。
- 預設只顯示該日期的標案資料。
- 可返回月份行事曆。
- 可切換到前一天或後一天。
- 可用關鍵字搜尋：
  - 標案名稱
  - 機關名稱
  - 標案案號
- 支援多關鍵字搜尋。
- 支援快速篩選按鈕，沿用 Excel 既有關鍵字。
- 支援地區篩選。
- 支援機關篩選。
- 支援招標方式篩選。
- 支援採購性質篩選。
- 支援公告日期區間。
- 支援截止投標日期區間。
- 支援預算金額區間。
- 支援只看尚未截止。

### 4.4 結果列表

列表需顯示：

- 機關名稱
- 標案名稱
- 招標方式
- 採購性質
- 公告日期
- 截止投標
- 預算金額
- 命中關鍵字
- 檢視

列表互動：

- 點擊欄位可排序。
- 點擊「檢視」可用預設瀏覽器開啟政府電子採購網標案頁。
- 點擊資料列也可開啟詳情面板；若使用者點擊檢視連結，則直接跳轉網頁。
- 可複製單筆標案資訊。
- 可收藏/標記標案。
- 可隱藏已讀或已排除標案。

### 4.5 篩選結果

需取代 Excel `篩選` 工作表功能：

- 以搜尋條件產生結果清單。
- 顯示 `機關名稱：標案名稱` 的合併文字。
- 保留標案詳情超連結。
- 可匯出為 Excel、CSV。

### 4.6 關鍵字管理

系統需提供關鍵字管理介面：

- 新增、編輯、刪除關鍵字。
- 將關鍵字分類，例如：
  - 資訊系統
  - XR/AI
  - ESG/碳管理
  - 地區
  - 指定機關
  - 倉儲/自動化
- 啟用/停用關鍵字。
- 可設定關鍵字搜尋欄位：
  - 標案名稱
  - 機關名稱
  - 全欄位

### 4.7 匯出

- 匯出目前日期與搜尋條件下的結果為 `.xlsx`。
- 匯出欄位需至少包含現有 Excel 欄位。
- 匯出的標案名稱或檢視欄需保留可點擊超連結。
- 匯出格式需適合使用者再用 Excel 篩選。

### 4.8 排程設定

- 預設每天 17:00 執行。
- 使用者可在設定頁調整執行時間。
- 可設定是否開機補跑。
- 可查看最近一次更新結果。
- 可手動測試排程是否正常。

## 5. 介面需求

### 5.1 主畫面

建議採用工作型桌面工具介面，不做行銷式首頁。第一畫面必須是月份行事曆，讓使用者先用日期掌握每天爬回的標案筆數，再進入指定日期的標案清單。

主畫面區塊：

- 上方工具列：
  - 上一月
  - 下一月
  - 回到本月
  - 立即更新
  - 排程狀態
  - 最近更新時間

- 中央月份行事曆：
  - 以月份格狀呈現。
  - 每格顯示日期與該日標案筆數。
  - 有資料的日期可點擊進入該日查詢頁。
  - 今日需醒目標示。
  - 排程失敗日期需顯示警示狀態。

- 側邊摘要：
  - 本月標案總數。
  - 今日標案數。
  - 最近一次更新結果。
  - 最近失敗紀錄。

### 5.2 日期資料查詢頁

使用者點擊行事曆日期後進入此頁，此頁承接原 Excel 工具的搜尋與篩選功能。

頁面區塊：

- 上方工具列：
  - 返回行事曆
  - 目前日期
  - 前一天/後一天
  - 搜尋框
  - 招標方式
  - 採購性質
  - 預算區間
  - 匯出

- 左側篩選面板：
  - Excel 既有快速關鍵字分類
  - 地區
  - 機關
  - 收藏/已讀/已排除

- 中央結果表格：
  - 顯示該日標案資料。
  - 支援排序、欄寬調整、快速複製。

- 右側詳情面板：
  - 顯示選取標案摘要。
  - 顯示詳情連結。
  - 顯示命中關鍵字。
  - 提供收藏、排除、開啟網頁。

### 5.3 視覺風格

- 乾淨、低干擾、適合每天查詢使用。
- 表格資訊密度要高，但保留足夠行距。
- 快速篩選按鈕可用標籤/晶片樣式呈現。
- 重要狀態用顏色提示：
  - 今日新增
  - 即將截止
  - 已截止
  - 高預算
  - 已收藏

## 6. 非功能需求

### 6.1 效能

- 10,000 筆以上資料仍需能快速搜尋。
- 本機搜尋回應時間建議小於 300ms。
- 爬蟲不可因單頁錯誤中斷整批任務。
- 因資料以每日 JSON 保存，查詢頁只需載入所選日期資料；首頁行事曆應優先讀取每日 `summary.json`，避免每次都解析完整標案資料。

### 6.2 穩定性

- 排程執行失敗需保留錯誤紀錄。
- 網站欄位異動時需能記錄解析錯誤。
- 同一天內資料寫入需避免重複。
- 不同日期的資料需分開保存，即使同一標案跨日出現，也需可追蹤它在哪些日期被抓到。
- 更新中斷時不可破壞既有 JSON 檔案。
- 寫入 JSON 時需採用暫存檔加原子替換策略，例如先寫入 `tenders.tmp.json`，成功後再替換為 `tenders.json`。

### 6.3 維護性

- 爬蟲查詢參數、招標方式對應、關鍵字清單需可設定。
- 不應把所有關鍵字硬寫在程式碼內。
- 日誌需方便工程人員排查。

### 6.4 合規與禮貌爬取

- 遵守政府電子採購網使用規範。
- 控制請求頻率。
- 加入合理等待與重試。
- 優先使用官方查詢頁可接受的查詢條件，不做高頻全文掃描。

## 7. 技術架構

本專案主要技術指定使用 C# 與 .NET 實作，目標平台為 Windows 本機桌面軟體。

### 7.1 技術選型

- 程式語言：C#
- 執行平台：`.NET 8` 或後續 LTS 版本
- 桌面 UI：`WPF`
  - WPF 對 Windows 桌面工具、表格、行事曆、自訂控制項與安裝部署支援成熟。
  - 若後續團隊已有 WinUI 3 經驗，可再評估，但首版以 WPF 為主要實作方向。
- 架構模式：MVVM
- 本機資料儲存：每日資料夾 + JSON 檔案
- JSON 處理：`System.Text.Json`
- 爬蟲：
  - 優先使用 `HttpClient` + `AngleSharp` 解析 HTML。
  - 若政府網站需要 JavaScript、session 或瀏覽器行為，改用 `Microsoft.Playwright` headless browser。
- 匯出 Excel：
  - 使用 `ClosedXML` 產生 `.xlsx`。
  - 匯出的標案名稱或檢視欄需保留超連結。
- 排程：
  - 首版使用 Windows Task Scheduler，每天 17:00 執行背景 CLI。
  - 若後續需要更完整的背景控制，再評估 Windows Service。
- 安裝包：
  - 使用 `WiX Toolset` 製作 MSI。
  - 若需求偏向簡單 EXE 安裝流程，可使用 `Inno Setup`。

### 7.2 建議專案型態

- `Tender.Desktop`
  - WPF 桌面應用程式。
  - 提供首頁月份行事曆、日期資料查詢、搜尋、篩選、匯出、設定。

- `Tender.Crawler`
  - .NET Console App。
  - 負責爬蟲、JSON 寫入、每日摘要產生。
  - 可由 Windows Task Scheduler 呼叫，也可由桌面 UI 手動觸發。

- `Tender.Core`
  - Class Library。
  - 放置資料模型、搜尋邏輯、關鍵字命中邏輯、日期處理、共用常數。

- `Tender.Storage`
  - Class Library。
  - 負責每日資料夾、JSON 讀寫、暫存檔原子替換、設定檔管理。

- `Tender.Installer`
  - 安裝專案。
  - 建立桌面捷徑、開始功能表捷徑、資料目錄與 Windows Task Scheduler 任務。

### 7.3 技術約束

- 不使用資料庫，包含 SQLite、Access、LocalDB 或其他嵌入式資料庫。
- 不以 Excel VBA 作為正式產品主體。
- 不要求使用者安裝 Excel、Python、Node.js 或其他開發環境。
- 所有每日標案資料需以 JSON 檔保存在本機資料目錄。
- UI 與背景爬蟲需共用同一套 C# 資料模型，避免欄位定義分歧。

## 8. 建議系統模組

- `Tender.Desktop`
  - 桌面 UI。
  - 月份行事曆首頁、日期資料查詢、搜尋、篩選、匯出、設定。

- `Tender.Crawler`
  - 命令列背景程式。
  - 可由 UI 手動呼叫，也可由排程呼叫。

- `Tender.Core`
  - 資料模型、搜尋邏輯、關鍵字命中邏輯。

- `Tender.Data`
  - JSON 檔案讀寫。
  - 每日資料夾管理。
  - 資料去重、更新紀錄。

- `Tender.Installer`
  - 安裝檔。
  - 建立資料目錄。
  - 建立 Windows Task Scheduler 任務。

## 9. 本機 JSON 檔案結構建議

系統不使用資料庫。所有資料均存放在使用者本機資料目錄內，並以日期分資料夾管理。

### 9.1 資料根目錄

建議路徑：

- `%LocalAppData%/TenderSearch/data/`

可在設定頁提供資料目錄位置顯示，但首版不一定需要讓使用者自訂。

### 9.2 每日資料夾

每日建立一個資料夾：

```text
data/
  2026-05/
    2026-05-08/
      tenders.json
      summary.json
      crawl-runs.json
      errors.log
```

資料夾命名：

- 月份資料夾：`yyyy-MM`
- 日期資料夾：`yyyy-MM-dd`

### 9.3 `tenders.json`

存放該日期抓到的標案清單。

```json
{
  "date": "2026-05-08",
  "generatedAt": "2026-05-08T17:05:30+08:00",
  "source": "https://web.pcc.gov.tw/pis/",
  "items": [
    {
      "sourcePk": "NzEyMTUxODc=",
      "agencyName": "機關名稱",
      "agencyCode": "機關代碼",
      "tenderName": "標案名稱",
      "tenderNo": "標案案號",
      "tenderMethod": "公開招標",
      "procurementType": "財物類",
      "announcementDate": "115/05/08",
      "bidDeadline": "115/05/12",
      "budgetAmount": 1000000,
      "detailUrl": "https://web.pcc.gov.tw/prkms/urlSelector/common/tpam?pk=...",
      "matchedKeywords": ["AI", "系統"],
      "createdAt": "2026-05-08T17:05:30+08:00",
      "lastSeenAt": "2026-05-08T17:05:30+08:00"
    }
  ]
}
```

同一天內需以 `sourcePk` 或 `detailUrl` 去重。

### 9.4 `summary.json`

供首頁月份行事曆快速讀取，不需載入完整標案清單。

```json
{
  "date": "2026-05-08",
  "totalCount": 52,
  "lastRunStatus": "success",
  "lastRunAt": "2026-05-08T17:05:30+08:00",
  "insertedCount": 52,
  "updatedCount": 0,
  "skippedCount": 0,
  "errorMessage": null
}
```

### 9.5 `crawl-runs.json`

記錄該日期每次爬蟲執行結果。

```json
{
  "date": "2026-05-08",
  "runs": [
    {
      "runId": "20260508-170000",
      "targetDate": "2026-05-08",
      "startedAt": "2026-05-08T17:00:00+08:00",
      "finishedAt": "2026-05-08T17:05:30+08:00",
      "status": "success",
      "insertedCount": 52,
      "updatedCount": 0,
      "skippedCount": 0,
      "errorMessage": null
    }
  ]
}
```

### 9.6 `keywords.json`

關鍵字設定可放在全域設定資料夾，例如：

```text
data/
  settings/
    keywords.json
    app-settings.json
```

`keywords.json` 建議格式：

```json
{
  "groups": [
    {
      "name": "資訊系統",
      "items": [
        { "keyword": "數位", "targetField": "tenderName", "enabled": true },
        { "keyword": "系統", "targetField": "tenderName", "enabled": true }
      ]
    }
  ]
}
```

### 9.7 `user-marks.json`

收藏、已讀、排除與備註可放在全域檔案，以標案 `sourcePk` 或 `detailUrl` 對應。

```json
{
  "marks": [
    {
      "sourcePk": "NzEyMTUxODc=",
      "isFavorite": true,
      "isRead": false,
      "isExcluded": false,
      "note": ""
    }
  ]
}
```

## 10. MVP 範圍建議

第一版建議先做：

- 首頁月份行事曆。
- 每日 17:00 自動抓取當天最新標案資料。
- 每日資料分天保存。
- 行事曆日期格顯示該日標案筆數。
- 點擊日期進入該日資料查詢頁。
- 手動立即更新。
- 本機每日資料夾與 JSON 儲存。
- 日期資料查詢頁搜尋與篩選。
- 沿用 Excel 關鍵字快速篩選。
- 標案列表與詳情連結。
- 匯出 Excel。
- 安裝檔建立桌面捷徑與排程任務。
- 更新紀錄與錯誤日誌。

第二版再做：

- 收藏/已讀/排除。
- 關鍵字管理完整 UI。
- 自動通知今日命中新標案。
- 標案詳情頁深度解析。
- 多使用者共享資料夾或雲端同步。

## 11. 主要風險與待確認事項

- 政府電子採購網查詢頁是否有反爬蟲、驗證碼或 session 限制。
- ~~`公開取得報價單或企劃書` 在目前查詢頁實際 option/value 需確認~~（已於 2026-05-11 確認為 TENDER_WAY_2）。
- 「當天最新標案」正式定義需確認，首版建議以公告日期等於當天作為條件。
- 同一標案若跨多日仍出現在查詢結果中，需確認是否每天都列入該日快照；首版建議只要該日查詢結果有出現，就保留於該日紀錄。
- 使用者是否需要多台電腦共用資料。
- 安裝環境是否允許系統管理員權限。
  - 若允許，Windows Service 較穩。
  - 若不允許，Windows Task Scheduler per-user 任務較容易部署。
